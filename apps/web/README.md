# Web App (MVP Scaffold)

Scope:
- Public match list and match detail views.
- Read-only join by default.
- Polling-based projection refresh for MVP.

Current files:
- `apps/web/index.html`
- `apps/web/src/main.ts`
- `apps/web/src/styles.css`

Run locally:
```sh
npm run build:web
npm run -w @hockey-timer/web serve
```

Backend expected at:
- `http://localhost:8787`
